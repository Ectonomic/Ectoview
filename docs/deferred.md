- **Untouched screen at fractional scale** (`package/contents/ui/Untouched.qml`, check `tests/e2e/check.py` "left as it was", marked known). A QML effect can't skip a screen (KWin's QuickSceneEffect::addScreen makes a view on every one, and a view without alpha draws black), so the untouched screen is redrawn from KWin's window thumbnails. KWin renders a thumbnail into a texture sized to the window's whole-pixel rect and draws it back over the fractional one (`WindowThumbnailSource::update`, KWin 6.7.5), so on a screen scaled 1.75 about 1.4% of pixels (text and line edges) soften while Ectoview is open. At scale 1 or 2 it holds (0.0002%). A real fix needs C++: a small effect plugin that hides the view (OffscreenQuickView::setVisible) on screens Ectoview leaves alone, which brings back a rebuild per KWin release.
- Desktops switching while Ectoview is open don't slide (Overview's `desktopOffsetForScreen` comes from EffectsHandler::desktopChanging, which a QML effect doesn't get; `package/contents/ui/main.qml` returns no offset).
- A swipe can start Ectoview while another full-screen effect is active (Overview's EffectTogglableState checks `effects->hasActiveFullScreenEffect()`, which QML can't read). Touch screen edges toggle at once instead of following the finger (`registerRealtimeTouchBorder` isn't open to QML).
- System Settings finds the settings page through `~/.config/plasma-workspace/env/ectoview.sh` (QT_PLUGIN_PATH), which a Plasma session reads at login: the page appears in System Settings after one log out and in. Until then the gear beside Ectoview's search field opens it (by the full path install.sh writes to SettingsModule). (A system-wide install under /usr would avoid this but needs root.)

- **COPR rebuilds on push** (1.0, November 17, 2026): the Fedora package at copr.fedorainfracloud.org/coprs/omgrant/ectoview is rebuilt by `copr-cli build-package` when a release is published, not by a GitHub webhook as Ectolens's is (the webhook's address comes from COPR's Integrations page, which needs the account's web login).
- **Packages beyond Fedora** (1.0): no AUR, openSUSE Build Service or Debian package; other distributions install from source with `install.sh`, which installs the build's packages for Fedora, openSUSE, Arch, Debian, Ubuntu and KDE neon.
- **Plasma older than 6.7** (1.0): refused by install.sh (Debian 13 has 6.3, Ubuntu 26.04 6.6, November 2026); the package requires kwin >= 6.7.
- **Plasma newer than 6.8** (1.0): install.sh lets it through with a warning; nothing has been tried on it.
- **X11**: Ectoview is tested on Wayland only.
